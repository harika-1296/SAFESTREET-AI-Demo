# SafeStreet AI
### Safety. Intelligence. Togetherness.

**An AI-powered personal and community safety platform designed to create safer streets, journeys and communities.**

---

## About the Project

SafeStreet AI is a technology-driven safety ecosystem that brings together artificial intelligence, location intelligence, emergency assistance and community participation.

The platform aims to help individuals access emergency support, identify potential safety risks, monitor journeys and report unsafe surroundings through one connected ecosystem.

With women's safety at its heart, SafeStreet AI is designed to support everyone — including students, commuters, travellers, elderly people and vulnerable communities.

**Our vision:** Build a world where people feel more informed, connected and supported through intelligent safety technology.

---

## The Problem

Personal and community safety remain significant challenges in everyday life.

- People may struggle to access timely emergency assistance.
- Individuals often lack reliable information about potentially unsafe locations.
- Sharing journey progress with trusted contacts can be difficult.
- Safety reports are frequently fragmented across different platforms.
- Emergency communication and response coordination can lack visibility.
- Communities need better ways to identify recurring safety concerns.

SafeStreet AI addresses these challenges through a unified, intelligent and community-driven platform.

## How It Works

SafeStreet AI follows a connected safety workflow:

1. **Identify:** A user reports an incident or a simulated AI event identifies a potential risk.
2. **Assess:** The system presents incident information and an AI-assisted risk assessment.
3. **Verify:** The user can verify a potential emergency before escalation.
4. **Connect:** Emergency information is made available to the appropriate demo response workflow and trusted contact notification flow.
5. **Respond:** Responders can acknowledge and update incident status.
6. **Analyse:** Administrators can review incidents and identify broader community safety patterns.

This approach connects individual safety experiences with community-level intelligence.

## Hackathon Demonstration Scenarios

The prototype is designed to demonstrate five end-to-end scenarios:

**01 — Emergency SOS**

A user activates SOS, an emergency incident is created, trusted contact notifications are simulated and the responder interface displays the incident.

**02 — AI-Assisted Emergency Detection**

A simulated distress pattern is detected, a risk assessment is displayed and the user is given an opportunity to verify the event.

**03 — Community Safety Reporting**

A user reports an unsafe location or infrastructure hazard. The report appears in the community feed and can be reviewed by an administrator.

**04 — Safe Journey Monitoring**

A user starts a journey, monitors its progress and receives a simulated alert when the expected arrival time is exceeded.

**05 — Offline Reporting**

A user creates a report while offline. It remains pending and demonstrates synchronisation when connectivity is restored.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Run Locally

**1. Clone the repository**

    git clone https://github.com/harika-1296/SAFESTREET-AI-Demo.git

**2. Open the project directory**

    cd SAFESTREET-AI-Demo

**3. Install dependencies**

    npm install

**4. Start the development server**

    npm run dev

**5. Create a production build**

    npm run build

Vite will provide a local development URL, typically `http://localhost:5173`.

## Prototype Status and Limitations

SafeStreet AI is currently a hackathon prototype demonstrating the proposed product experience and connected workflows.

The prototype uses simulated services and sample data where real integrations are not available.

The following distinctions are important:

- AI emergency detection is demonstrated through simulated events, not validated production AI.
- Emergency notifications and responder actions are simulated.
- Real police or emergency-service dispatch is not implemented.
- Map and location experiences may use demonstration data.
- Offline synchronisation is a prototype demonstration, not a guarantee of emergency communication.
- Production deployment would require secure backend services, verified integrations, privacy controls and extensive real-world testing.

AI assessments are advisory and must not be treated as confirmed emergencies. Manual SOS must remain independent of AI detection.
